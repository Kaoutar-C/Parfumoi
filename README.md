Parfumoi

📌 Description du projet
Ce projet est une plateforme de revente entre particuliers dédiée aux parfums de niche.

L'objectif est de permettre aux passionnés de vendre et acheter des parfums authentiques en toute sécurité.
Contrairement aux plateformes classiques, ce site met l'accent sur :
•	la lutte contre les contrefaçons
•	la vérification des parfums grâce à un numéro de série
•	les échanges en main propre pour garantir l'authenticité.
Le site s'adresse principalement aux amateurs de parfums de niche qui souhaitent acheter, vendre ou échanger leurs fragrances.

🎯 Objectifs
•	Faciliter la revente de parfums de niche entre particuliers
•	Réduire le risque de contrefaçons
•	Créer une communauté de passionnés
•	Garantir des transactions sécurisées en main propre

🔐 Système anti-contrefaçon
Pour éviter la vente de parfums contrefaits, chaque parfum mis en vente doit inclure :
•	un numéro de série
•	une photo du flacon et de la boîte
•	des informations sur la marque et le parfum
Le numéro de série permet de vérifier l’authenticité du produit.

🤝 Fonctionnement des ventes
1.	Un utilisateur crée un compte.
2.	Il peut publier une annonce pour vendre un parfum.
3.	L’annonce doit contenir :
o	nom du parfum
o	marque
o	état (neuf / utilisé)
o	numéro de série
o	photos
o	prix
4.	Un acheteur intéressé contacte le vendeur.
5.	La transaction se fait en main propre pour garantir l’authenticité du parfum.

🧑‍🤝‍🧑 Utilisateurs ciblés
•	collectionneurs de parfums
•	amateurs de parfums de niche
•	personnes souhaitant revendre des parfums peu utilisés
•	passionnés de fragrances rares

✨ Fonctionnalités principales
•	création de compte utilisateur
•	publication d’annonces
•	recherche de parfums
•	filtrage par marque ou parfum
•	vérification via numéro de série
•	contact entre acheteur et vendeur
•	ventes en main propre

🧴 Types de parfums
La plateforme est dédiée uniquement aux parfums de niche, par exemple :
•	Maison Francis Kurkdjian
•	Byredo
•	Parfums de Marly
•	Xerjoff
•	Nishane
•	Amouage

🚀 Évolutions possibles
Améliorations futures du projet :
•	système de notation des vendeurs
•	messagerie intégrée
•	géolocalisation pour faciliter les rencontres
•	système de signalement de contrefaçons
•	base de données de numéros de série vérifiés
